# Regras de execução de tasks
1. Branch nova para cada spec, ex: feat/MVP
2. Cada task da spec equivale a um commit
3. Push da branch ao fim da spec
4. Abrir PR contra a main
5. Verificar se há conflifto
6. Se houver conflito e for simples, corrigir e atualizar PR com o que foi resolvido
7. Se houver conflito e envolver decisão de lógica, perguntar e aguardar decisão
8. Merge em main apenas se houver comando claro
